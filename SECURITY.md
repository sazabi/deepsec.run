# Security Policy

## Reporting a vulnerability in DeepSec.run

If you find a security vulnerability in the DeepSec.run service, email [security@sazabi.ai](mailto:security@sazabi.ai). Do not file a public GitHub issue or include exploit details, customer data, source code, or scan reports in a public channel.

We will coordinate a disclosure date with you before publishing.

## Vulnerabilities found in scanned repositories

DeepSec.run reports findings privately to the GitHub account that requested the scan. This repository is not a disclosure channel. Report a vulnerability in another product to its vendor or maintainer, or to a CVE Numbering Authority.

## Vercel

deepsec is an open-source project from Vercel. deepsec.run is operated by Sazabi and is not a Vercel product, nor is it operated, endorsed, or affiliated with Vercel. Report vulnerabilities in Vercel products to [Vercel's security team](https://vercel.com/security).
