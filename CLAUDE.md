# DeepSec.run public issue tracker

This repository is the public project page and issue tracker for deepsec.run, Sazabi's hosted service for the open-source deepsec security review tool. It scans eligible public or private GitHub repositories and gives each repository owner a private report. It contains documentation, issue forms, and the trust-core package `packages/deepsec-run-core` (what runs in the scan sandbox, its egress policy, scan limits, and telemetry allowlist); the rest of the application source, customer repositories, and scan reports stay private.

This is a release mirror of files maintained in Sazabi's private monorepo. Do not commit changes here; they will be overwritten. Open an issue for product feedback or a bug report. Never put credentials, customer data, private repository names, scan reports, or unpatched vulnerability details in a public issue. For a vulnerability in DeepSec.run, use the private address in `SECURITY.md`.

deepsec is an open-source project from Vercel. deepsec.run is operated by Sazabi and is not a Vercel product, nor is it operated, endorsed, or affiliated with Vercel.
